# История изменений

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии приложения — `versionName` из `app/build.gradle.kts`.

## [1.1] — 2026-11-02

### Добавлено

- Два варианта сборки: `full` — все вкладки, `lite` — только Bluetooth
  (поиск, спаривание и журнал), отдельный пакет `com.dash.btmanager.lite`
  и имя «Bluetooth Manager Lite».
- Вкладка «Данные»: диалог «Какие данные показывать» — можно скрыть ненужные
  величины; выбор запоминается отдельно для каждого профиля.
- Встроенный сводный профиль Chery Tiggo 7 / 7 Pro / 7L (1.5T/1.6T) + DCT
  с параметрами ECM, TCM, ABS/ESP, TPMS и DCT, сверенными по логу Car Scanner.
- Тест разбора встроенного профиля Chery Tiggo 7.
- `app/proguard-rules.pro` с правилами R8 для release-сборок.

### Изменено

- Release-сборки проходят через R8 (`isMinifyEnabled` + `isShrinkResources`):
  в `lite` недостижимый OBD-движок вырезается, в `full` — неиспользуемый код.
- CI собирает и публикует оба APK — `bt_manager-full-release.apk`
  и `bt_manager-lite-release.apk`; на тегах `v*` оба прикрепляются к GitHub Release.
- В `lite` скрыты вкладки OBD, «Данные» и «Экран», пункт «Сделать адаптером OBD»
  и бейдж OBD в списке устройств.
- README дополнен разделами о вариантах сборки, CI и R8.

### Исправлено

- В `lite` больше не запрашивается разрешение `READ_EXTERNAL_STORAGE`:
  оно объявлено только в `app/src/full/AndroidManifest.xml`, так как lite
  не читает профили с флешки.

## [1.0] — 2026-10-31

### Добавлено

- Приложение под горизонтальный экран ГУ (1920×720, Android 9 / API 28),
  оформленное как настройки автомобиля.
- Вкладка Bluetooth: включение адаптера, скан, спаривание с автоответом PIN,
  список спаренных и найденных устройств, журнал, тест SPP-подключения.
- Вкладка OBD · ELM327: выбор адаптера и профиля, состояние связи,
  сетка показателей и журнал обмена «команда → ответ».
- Вкладка «Данные»: загрузка JSON-профилей с флешки или через файловый диалог,
  выбор профиля, показ величин по группам.
- Вкладка «Экран»: темы «Классика» и «Комфорт», версия приложения.
- Движок OBD: парсер ответов ELM327, формулы величин, профили с CAN-заголовками,
  ISO-TP (многокадровые ответы, VIN), стандартный набор OBD-II.
- Примеры профилей: стандартный OBD-II и Chery Tiggo 7/8 Pro / Omoda C5 + DCT,
  собранный по фактическим ответам Car Scanner.
- Юнит-тесты парсера ответов, формул и примеров профилей.
- GitHub Actions: сборка и тесты на каждый пуш, release APK на тегах `v*`.
- Скриншоты вкладок и документация в README.

### Изменено

- Масштаб интерфейса увеличен до 1.15 — шрифты и элементы чуть крупнее.
- С вкладок Bluetooth и OBD убраны картинки, журнал занимает всю высоту.
